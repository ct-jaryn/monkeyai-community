# Security policy

Please do not publish vulnerabilities, credentials, private data, or exploitable details in an issue or pull request. Use [GitHub private vulnerability reporting](https://github.com/ct-jaryn/monkeyai-community/security/advisories/new) for this repository. Provide the affected component, impact, minimal reproduction, and a safe way to contact you through the advisory. Never include real secrets or private user data.

This policy covers the community website repository. For vulnerabilities in the upstream MonkeyAI product or third-party tools, follow the relevant project's security policy instead. Maintainers review reports on a best-effort basis; no response-time guarantee or bug bounty is implied.
